# God's Eye Solana Audit MCP & AgentCash Skill

MCP server and portable agent skill for God's Eye x402 API (https://godseyex402.dpdns.org) — $0.03 token bundle/telemetry audits and $0.02 deployer checks in USDC on Base or Solana.

## Use with AgentCash
    npx agentcash@latest install -y
    npx skills add Aliyuava/gods-eye-mcp

## Run as Standalone MCP Server
    uvx --from git+https://github.com/Aliyuava/gods-eye-mcp gods-eye-mcp
